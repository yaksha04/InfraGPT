# Project Synopsis: InfraGPT
## Autonomous Kubernetes Site Reliability Engineering & Cluster Governance Platform

---

### 1. Title of the Project
**InfraGPT: AI-Powered Autonomous Site Reliability Engineering & Kubernetes Cluster Governance with Model Context Protocol (MCP)**

### 2. Team Members & Roles
* **Akshat (Project Lead):** AI/ML Architecture, LLM Function Calling, Orchestrator Engine.
* **Yaksha:** Cloud Infrastructure, Docker Compose, Kubernetes RBAC & Manifests.
* **Bhoomi:** Cyber-Ops React Dashboard, UI State Management, System Documentation.

### 3. Problem Statement
Distributed Kubernetes systems suffer from alert fatigue, distributed log fragmentation, and delayed Mean Time To Detect (MTTD) during production incidents. Traditional monitoring tools (e.g. Prometheus/Grafana) report symptoms but cannot autonomously investigate root causes or apply validated remediations safely.

### 4. Proposed Solution
InfraGPT provides an intelligent, natural-language conversational interface that autonomously conducts multi-step SRE diagnostic trees across pods, nodes, events, and logs. It incorporates a strictly governed Human-In-The-Loop (HITL) authorization state machine to ensure zero unverified mutating actions reach the cluster.

### 5. Tech Stack & Technologies Used
* **AI & LLM:** Google Gemini 2.5 Flash / Gemini 3.5 Flash, FastMCP (Model Context Protocol).
* **Backend Tier:** Python 3.11, FastAPI, Uvicorn, Pydantic, Kubernetes Python Client.
* **Frontend Tier:** React 18, Vite, Tailwind CSS, Lucide Icons, ReactMarkdown.
* **Infrastructure & Containerization:** Docker, Docker Compose, Kubernetes (Docker Desktop / Minikube).

### 6. Hardware & Software Requirements
* **OS:** Windows 10/11, macOS, or Linux (Ubuntu 22.04+).
* **RAM:** Minimum 8 GB (16 GB Recommended).
* **Runtime:** Python 3.11+, Node.js 20+, Docker Desktop with Kubernetes enabled.
